# Etch

Etch previews Europa Universalis IV 1.37.5 interface mods in Visual Studio
Code while they are edited.

This release has no features yet: it is the foundation of the extension.
See the [v1 specification](https://github.com/happy-dwarf-team/etch/blob/main/docs/spec/v1.md)
for what 1.0.0 contains and in what order it is built.

Etch sends nothing anywhere: it has no telemetry.
