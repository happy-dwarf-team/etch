# Etch v3 specification (draft)

**Status: draft.** Started from the grilling of 2 November 2026, whose first
question was how well Etch shows *every* view of the game. It holds what v3 is
for, the coverage survey that measures it, the targets and the work the first
survey found. Everything else Etch does stays as the
[v2 specification](v2.md) says; its open points stay in
[after-v2.md](after-v2.md) until this draft takes them up.

## 1. Target

Etch v3 is the release a mod author can trust for **any** window of vanilla and
Anbennar, and for a window of their own mod: the outline draws every widget
where the game draws it, the preview shows and hides what the game would, and a
live snapshot puts into the preview everything the game showed. v2 proved this
for the 16 views of the precision corpus; v3 proves it for every view a player
can open, and says how far the proof carries to windows nobody measured.

## 2. The coverage survey

Decided in the grilling (questions Q1–Q16); the method is
[docs/coverage.md](../coverage.md):

- **A view** is a state of the screen a player opens (Q1), told apart by its
  signature; every top-level `.gui` window is a view's root, inside a view, or
  not reached, with the reason.
- **Playsets** (Q2, Q16): vanilla and Anbennar alone are crawled; Bigger UI
  V1.37 is the holdout, measured once on vanilla's views before any fix and
  reported apart. The P2K playsets follow for the views their mods change.
- **Finding the views** (Q6, Q12–Q14): a crawler clicks, breadth first and three
  steps deep, every shown and enabled button and check box (first rows only),
  the survey's keys and provinces of each kind, keeps the game's state with a
  fingerprint and fresh starts, and never confirms an action. Each view's
  recipe is checked by capturing it from a fresh start.
- **Resolutions** (Q5): 1920×1080 for every view; 1280×720 for the views with a
  small variant.
- **Game calls** (Q4, Q7): allowed in the survey, never in the corpus, and marked
  per view. The first survey made none.
- **Measures** (Q3, Q8–Q10, Q15): the outline offline (geometry and visibility),
  the preview from the live snapshot (geometry, visibility, texts), pixels by
  the corpus comparison (reported), and constructs with a window's confidence.
- **Results** (Q11): [docs/coverage-results.md](../coverage-results.md), one
  issue per class of failure, fixes by their own pull requests.

## 3. Targets and the release gate

| Measure | Target | Gates 3.0.0 |
| --- | --- | --- |
| Outline geometry, every surveyed view | 100 % of compared rects exact | yes, for the views of a profiled window; reported for the rest |
| Visibility, views of a profiled window, from the live snapshot | 100 % | yes |
| Live snapshot texts, profiled windows | 100 % of the texts the game shows | yes |
| Pixels of surveyed views | reported | no; the precision corpus keeps its gate (ADR 0002) |
| Holdout | reported apart, once | no |
| Windows not reached | each with a reason; confidence reported | no |

A difference is a bug or a known deviation with an issue and the maintainer's
consent, never a tolerance, as in ADR 0002.

## 4. Compare with Live Game

A command for the mod author's own windows (Q15 b): **Etch: Compare with Live
Game** takes, for the previewed window the game has open, the same measures as
the survey (rects, visibility, the snapshot's fields) and lists every
difference in Problems, with the widget's file and line. It reuses the survey's
comparison in `@etch/core` (`outlineGeometry`, `visibilityAgreement`,
`textAgreement` and the preview's path from a snapshot), so the survey and the
command cannot drift apart; the preview's own snapshot path moves into
`@etch/core` with it. Not built in this draft's first pull request.

## 6. Open points

- Views that Escape does not close (the outliner's options) are found but not
  captured: the capture driver goes from view to view with Escape.
- Views behind a confirmation (declaring war, sending a diplomat) are reached
  only up to the dialog; the corpus's `diplomacy-dialog` shows that one such
  dialog is reachable by a recipe.
- Country-specific views (the emperor's, the Pope's controller's, a colonial
  nation's) need another country, which a console `tag` on a private copy of
  the save would give (Q7); not done in the first survey.
