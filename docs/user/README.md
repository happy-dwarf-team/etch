# Etch's user docs

How to use Etch, for modders: every feature and setting, in plain language. The Etch website
shows these pages at [etch.happydwarf.dev/docs/](https://etch.happydwarf.dev/docs/), built from
the latest release; here they can be read on GitHub as they are on `main`. How to write them:
[STYLE.md](STYLE.md).

The folders are the groups of the site's sidebar, in this order:

- **Getting started**: [Install and requirements](getting-started/install.md) ·
  [Your first preview](getting-started/first-preview.md) ·
  [Where Etch finds the game](getting-started/finding-the-game.md)
- **Interface windows**: [Preview](interface-windows/preview.md) ·
  [Views and window profiles](interface-windows/views.md) ·
  [Sample data](interface-windows/sample-data.md) ·
  [Widget Outline](interface-windows/widget-outline.md) ·
  [Zoom and resolution](interface-windows/zoom-and-resolution.md) ·
  [Problems](interface-windows/problems.md)
- **Textures and meshes**: [Texture preview](textures-and-meshes/texture-preview.md) ·
  [Mesh preview](textures-and-meshes/mesh-preview.md) ·
  [Entities](textures-and-meshes/entities.md) · [Map trees](textures-and-meshes/map-trees.md) ·
  [Hovers and links](textures-and-meshes/hovers-and-links.md)
- **The live game**: [Start and stop](live-game/start-and-stop.md) ·
  [Reload on save](live-game/reload-on-save.md) · [Pick mode](live-game/pick-mode.md) ·
  [Snapshot and compare](live-game/snapshot-and-compare.md) ·
  [Run selection](live-game/run-selection.md) ·
  [The private install](live-game/private-install.md)
- **Scripts**: [Province IDs and names](scripts/province-ids-and-names.md) ·
  [Encoding](scripts/encoding.md) · [Script profile](scripts/script-profile.md) ·
  [Localisation texts](scripts/localisation-texts.md)
- **Reference**: [Commands](reference/commands.md) · [Settings](reference/settings.md) ·
  [Glossary](reference/glossary.md)
- **About**: [Limits](about/limits.md) ·
  [What Etch reads and writes](about/reads-and-writes.md) · [Accuracy](about/accuracy.md) ·
  [Etch 1.x](about/etch-1x.md)

The site adds the Changelog page to About, built from [CHANGELOG.md](../../CHANGELOG.md), and
lists every command and setting under the introductions of Commands and Settings, from
`packages/extension/package.json`.
